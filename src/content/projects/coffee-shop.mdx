## О проекте

Разработка полноценного сайта для сети кофеен с 15 точками в городе. Главная задача — объединить онлайн и офлайн-покупателей в единую экосистему.

### Ключевые возможности

- **Меню с фильтрами** — по категориям, составу, аллергенам, цене
- **Карта кофеен** — с реальным временем ожидания и загруженностью
- **Онлайн-заказ** — с самовывозом или доставкой через партнёров
- **Программа лояльности** — накопление баллов, персональные скидки, дни рождения
- **Интеграция с CRM** — синхронизация заказов, клиентов и остатков в реальном времени

### Технические детали

Фронтенд на Next.js с ISR для меню и карты. API на Go с PostgreSQL, всё запаковано в Docker и развёрнуто на одном VPS. Пагинация, кеширование, оптимизация изображений — всё из коробки.

### Результат

Средний чек вырос на 23% за счёт онлайн-заказов. Программа лояльности привлекла 4 200+ активных участников за первые 3 месяца.
