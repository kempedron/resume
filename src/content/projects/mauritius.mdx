## О проекте

Некоммерческий проект для фонда сохранения природы острова Маврикий. Цель — собирать пожертвования на конкретные проекты: очистка пляжей, спасение черепах, восстановление кораллов.

### Ключевые возможности

- **Фотогалерея проектов** — с описанием текущего состояния и целей сбора
- **Карта проектов** — интерактивная карта с метками активных и завершённых инициатив
- **Форма пожертвований** — разовый и регулярный платёж через Stripe
- **Telegram-уведомления** — бот присылает подтверждение донаторам и отчёт кураторам
- **Достижения** — публичная лента последних пожертвований

### Технические детали

Сайт полностью статический на Astro — максимальная скорость загрузки и дешёвый хостинг. Stripe Elements для приёма платежей на стороне клиента. Telegram Bot API для уведомлений.

### Результат

За первые полгода собрано $12 000+ на 3 проекта. Конверсия посетителей в донаторов — 4.2%, что в 1.5 раза выше среднего по сектору.
