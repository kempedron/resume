## О проекте

Разработка новостного портала для регионального медиа-холдинга. Проект рассчитан на высокую нагрузку: до 100 000 уникальных посетителей в день.

### Ключевые возможности

- **Лента новостей** — с бесконечной подгрузкой и приоритетом по важности
- **Категории и теги** — гибкая система рубрик и перекрёстных ссылок
- **Авторизация редакторов** — разделение прав: автор, редактор, главный редактор, админ
- **Админ-панель** — WYSIWYG-редактор, планировщик публикаций, модерация комментариев
- **RSS-подписка** — генерация лент по рубрикам
- **Поиск** — полнотекстовый через триграммы PostgreSQL

### Технические детали

Бекенд на Go с Redis для кеширования топ-новостей. Фронтенд на React без SSR — статика + Client-Side Rendering. Статьи кешируются на CDN, инвалидация при редактировании через webhook.

### Результат

Скорость загрузки страниц — менее 1 секунды при пиковых нагрузках. SEO-оптимизация вывела портал в топ-3 региональных СМИ по органическому трафику.
