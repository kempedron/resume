## О проекте

Разработка сайта для компании, предоставляющей услуги по ремонту квартир и домов. Основная задача — превратить посетителей в заявки через удобный калькулятор и портфолио.

### Ключевые возможности

- **Каталог услуг** — с ценами, сроками и примерами работ
- **Калькулятор стоимости** — выбор типа помещения, объёма работ, материалов;
- **Портфолио** — фотографии до/после с фильтрацией по типу работ
- **Отзывы** — с верификацией по номеру телефона
- **Онлайн-запись** — выбор даты и времени, напоминание за 24 часа
- **Личный кабинет клиента** — статус заказа, чат с прорабом, документы

### Технические детали

Vue.js на фронте с кастомным калькулятором. Go-бекенд с REST API, PostgreSQL с full-text поиском. Докеризация, CI/CD через GitHub Actions, деплой на VPS с авто-бекапами.

### Результат

Калькулятор увеличил конверсию в заявку на 40%. Средний чек вырос на 15% за счёт доп. услуг, которые клиенты видели в калькуляторе.
